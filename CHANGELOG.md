# Operator Desktop 0.3.8

## Скорость и надёжность

- Длинная лента сообщений отображает историю порциями, чтобы обновления ответа
  не пересобирали весь диалог. Предыдущие сообщения открываются по запросу.
- Потоковые обновления интерфейса объединяются в один кадр, чтобы кнопки и
  управление оставались отзывчивыми во время долгой работы агента.
- История сессий сканируется ограниченным параллелизмом; старый диалог
  восстанавливается до загрузки списка моделей и команд.
- Новую версию можно загрузить и установить из Desktop. Манифест приходит с
  официального сайта, а SHA-512 проверяется до запуска установщика.

# Operator Desktop 0.3.7

- Логотипы Alem Plus и Ollama отображаются отдельно в списке моделей, выбранной
  модели и окне ключей доступа. Пропорции сохранены; у Ollama скрыты только
  прозрачные поля исходного холста, знак целиком остаётся видимым.
- Список моделей автоматически показывает установленные записи Ollama, включая
  облачные, даже при выключенном сервере. Для них указаны источник и состояние
  сервера. Открытие списка обновляет модели без перезапуска приложения.
- Обнаружение Ollama работает через встроенный Node HTTP без зависимости от curl,
  учитывает `OLLAMA_HOST` и `OLLAMA_MODELS` и имеет ограничение ожидания.
- В счётчике «N в фоне» используется существующая иконка фонового процесса
  (облако с запуском) вместо вращающегося индикатора загрузки.
- Добавлены два оригинальных мягких звука: завершение ответа и запрос ввода
  или разрешения. Промежуточные шаги, повторы, отмена и загрузка истории молчат.
- В меню «… → Звуковые уведомления» доступны выключатель, громкость и
  прослушивание обоих сигналов. Настройки сохраняются на устройстве.

# Operator Desktop 0.3.6

## Скорость и надёжность

- Qwen корректно сообщает поддержку thinking. В новых диалогах он выключен;
  переключатель в интерфейсе управляет настоящим `enable_thinking` в запросе.
- Настройки провайдера и `modelOverrides` применяются к встроенным моделям Alem AI.
  Каждый запрос получает явный лимит выходных токенов.
- Найденные инструменты MCP сохраняются в небольшом кеше: до шести схем в пределах
  32 тысяч символов. Новый поиск не выгружает сразу предыдущий нужный инструмент.
- Повторяющиеся ошибки вызывают пересмотр подхода; при устойчивом отсутствии
  прогресса агент возвращает честный статус. Полезная длинная работа не ограничена
  числом шагов. Новое сообщение пользователя возобновляет доступ к инструментам.
- Старые большие выводы инструментов сокращаются только в отправляемом контексте.
  Оригиналы доступны по указанным путям и остаются в истории. В режиме Off старые
  рассуждения Qwen не отправляются повторно. Память возвращает короткие выдержки
  и пути к полным записям.
- Динамические обновления посторонних элементов страницы больше не отменяют
  действие. Изменённая, заменённая или недоступная цель по-прежнему отклоняется.
- `browser.upload` выбирает явно указанные файлы, включая скрытые поля загрузки.
  `browser.wait` ограниченно ждёт появления текста и возвращает свежее состояние.
- Название диалога создаётся без инструментов, расширений и контекста проекта.
  Автообнаружение Ollama имеет ограничение ожидания.
- Исправления ядра хранятся в `core-overrides` с проверкой исходных и итоговых
  контрольных сумм; обычная сборка включает их автоматически.

## Проверки

- `npm run check:performance`: запросы SDK, переключение thinking, лимиты,
  применение настроек, кеш инструментов, сохранность контекста и выход из повторов.
- `npm run check:performance-live`: пять сценариев на реальном Qwen с синтетическими
  файлами, включая исправление кода с запуском теста и обработку недоступного сервиса.
- `scripts/browser-check.ts`: динамические страницы, актуальность целей,
  отправка файла локальному серверу, скрытые/множественные поля и ожидание текста.
- `scripts/desktop-performance-check.py`: собранный Desktop, RPC, Qwen и загрузка
  файла на локальный сервер в изолированном профиле и истории.

# Operator Desktop 0.3.5

## Исправлено

- Для Alem AI Qwen3-8 / Qwen3.8 установлен лимит контекста 258 000 токенов.
  Старое пользовательское значение выше этого лимита также ограничивается.
- Автоматическое сжатие запускается заранее: при стандартных настройках Qwen
  примерно на 206 400 токенах. Остаётся запас для ответа и результатов инструментов.
- Порог проверяется перед новым запросом, между вызовами инструментов и после ответа.
- Ожидание ответа для сводки ограничено 45 секундами. Пустые, оборванные и незавершённые
  сводки не сохраняются как успешный результат.
- Если получить сводку не удалось, создаётся резервный локальный контекст с запросами,
  ограничениями и недавними действиями. Полная история сохраняется; интерфейс показывает
  информационное сообщение, а агент продолжает незавершённую задачу.
- Отмена сжатия останавливает его, не запускает резервное продолжение и не выдаёт
  отмену за сетевую ошибку.
- После сжатия счётчик показывает оценку оставшегося контекста, вместо сброса в ноль.
- Подсчёт токенов работает и с ответами без полей статистики кеша.
- Опасные команды проверяются в обычном и фоновом запуске, включая длинные флаги.
  При отсутствии канала подтверждения действие блокируется.
- «Разрешить всегда» сохраняет точное действие с аргументами, а не разрешение
  на любые команды той же программы.
- Добавлены ограничения ожидания ответов RPC и очистка ожидающих запросов при сбоях.

## Добавлено

- Понятные сообщения об отсутствии интернета, ожидании ответа, обрыве соединения,
  неверном ключе, перегрузке сервиса и лимитах.
- 13 собственных SVG-иконок для разных причин ошибок, включая ошибки в истории диалога.
- Иконка облака с запуском для фоновых задач, видимая во время запуска и после него.
- Проверки сжатия с пустым ответом, ошибкой сервиса, незавершённой сводкой,
  зависанием, отменой, продолжением задачи и сохранением исходной истории.
- Живые проверки порогов 80% и 85% на синтетической истории Qwen с результатом
  инструмента 64 КиБ. В стресс-сценарии 85% допустил переполнение и восстановился,
  а 80% сжал контекст до следующего запроса и продолжил без переполнения.
  В рабочей настройке сохранён порог 80%.
- Все каталоги MCP подключают схемы инструментов по запросу, включая небольшие
  серверы. По умолчанию поиск загружает один инструмент; ненужные схемы удаляются
  при следующем поиске и перед новым запросом пользователя.
- Стандартная порция `read_full` уменьшена с 250 до 64 КиБ. Продолжение чтения
  и явный запрос большей порции сохраняются.

## Обновление

Для Windows сохраняется идентификатор приложения и существующая папка установки:
установщик обновляет копию Operator, сохраняя диалоги, ключи, настройки и плагины.
Для Linux сохраняется то же имя пакета и профиль пользователя.
Windows: закройте Operator, запустите установщик 0.3.5 и нажмите «Обновить».
Linux: обновите существующий пакет через `apt install ./Operator-0.3.5-linux-amd64.deb`
или `pacman -U ./Operator-0.3.5-linux-x64.pacman` с правами администратора.
Для AppImage замените прежний файл новым. Удалять приложение и профиль не нужно.
Обновление требует загрузки файла соответствующего формата; автоматическая
установка и загрузка только изменённых частей в этой версии не добавлены.
